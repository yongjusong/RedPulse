# 특허 출원 명세서

## 발명의 명칭
**데이터센터 인프라 장애 예방을 위한 가상 합성 데이터 및 단기 텔레메트리 관측 융합 기반 다계층 SSD 수명 궤적 예측 시스템**

---

## 발명키워드
1. 반도체 기반 저장장치 잔여 수명 예측 (Solid State Drive Remaining Useful Life Prediction)
2. 시계열 기계 학습 모델링 (Time-Series Machine Learning Modeling, Long Short-Term Memory)
3. 다계층 하드웨어 타겟팅 격리 (Multi-Tier Hardware Targeting Isolation, Node-to-Drive)
4. 소프트웨어 정의 물리 마모 시뮬레이션 (Software-Defined Physical Wear Simulation)
5. 무설정 엣지 텔레메트리 연동망 (Zero-Touch Edge Telemetry Discovery)
6. 이종 병합 스토리지 캐싱 (Hybrid Storage Caching, Device-Mapper 계층 구조)

---

## 발명의 배경
대규모 클라우드 환경에서는 하나의 물리 서버(Node) 내부에 많게는 수십 개의 NVMe SSD (Drive)가 혼재되어 작동합니다. 각기 역할(캐시, 데이터 저장 등)과 밴더사 모델이 다름에도 기존의 분석 체계는 서버 단위의 통계에 매몰되어 정확한 개별 수명 예측 및 경제적 TCO 계산(FinOps)을 실패하게 만들었습니다. 

본 발명은, 복잡성을 지닌 하이브리드 캐시 구조와 멀티 디스크 환경하에서도 1) **물리 장비의 훼손 없이**, 2) **네트워크 관리자의 연결 개입 없이(Zero-Touch)**, 3) **특정 물리 슬롯 넘버(Drive ID)까지 완벽하게 격리된 데이터**만을 추출해 맹점 없는 초정밀 인텔리전스를 달성하고자 창안되었습니다.

## 발명설명1 (구조 관점 핵심 청구 항목)
1.  **계층형 데이터 격리 쿼리 파이프라인 (2-Depth Node-to-Drive Isolation Schema)**: 프론트엔드가 백엔드와 연결될 때 단일 묶음 노드를 조회하는 것이 아니라, `1단계 노드 토폴로지 추출 ➔ 2단계 해당 노드의 세부 디바이스 트리 매핑` 구조로 DB에 쿼리하여, 이기종 스토리지 데이터가 LSTM 인퍼런스 엔진에 유입되어 가중치를 붕괴시키는 데이터 오염 현상을 논리적으로 차단하는 필터 아키텍처.
2.  **무설정 단방향 엣지 통신망 (Zero-Touch Push Auto-Discovery)**: 인프라 관리자가 방화벽 포트 맵핑이나 프론트엔드 시스템 연동을 위해 IP를 셋업할 필요 없이, 가장 말단의 리눅스 에이전트 데몬이 단순히 HTTPS 표준 아웃바운드로 `API_KEY`와 호스트네임을 쏴주는 즉시 중앙 DB가 이를 수용하고 대시보드(Frontend)의 콤보박스에 디바이스가 렌더링되게 만드는 무상태 연결 지향성 네트워크 모델.
3.  **Synthetic Dataset Generator (Zero-Day 가상 마모 생태계)**: 모델의 물리적 임계점 공식과 디바이스 매퍼 특성을 결합하여 과거 고장 이력 없이도 가상의 노후화 로그 템플릿을 무한히 직조해 내는 고유 모듈.

## 발명설명2 (동작 관점 순서도)
1. **[실측 관측 - 자가 등록] 텔레메트리 에이전트 설치 (S100)**: 
   운영 노드의 리눅스 데몬이 백엔드 주소로 디바이스 스펙과 호스트네임 페이로드를 단방향 Push하며 자동 등록 절차 완료. 프론트엔드 연결 개입 없음.
2. **[2-Depth 타겟팅] 계층적 드릴-다운 렌더링 (S200)**: 
   관제사가 웹 앱에서 타겟 노드를 지목하면, 그 즉시 API가 호출되어 해당 노드 내부의 개별 NVMe 드라이브 식별자(SSD 번호)를 호출하여 2차 Datalist 콤보박스를 오픈.
3. **[AI 가속 예측 - 오염 격리 매칭] 특징 벡터 기반 단발적 장기 외삽 (S300)**: 
   2-Depth 파라미터가 모두 충족된 상태에서 Run 버튼 클릭 시, 섞임 없는 순수한 단일 디바이스의 WAF/Temp 특징 벡터만이 LSTM 엔진으로 포워딩 됨.
4. **[가시화 - 경제적 통찰] TCO FinOps 발행 (S400)**: 
   최종 도출된 해당 디스크의 잔여 수명과 95% Confidence Interval 바운더리 결과를 바탕으로 기업 설비 교체 감가상각 가치(TCO)를 최적화하는 경제적 권고 일정 표출.

## 발명의 활용 및 침해 판독 지표
*   **다계층 콤보박스 선택 UI/UX 워크플로우 탐지**: 경쟁 솔루션의 소프트웨어 UI 체인에서 서버명을 선택하자마자 서버 내부의 스토리지 식별자 ID를 비동기 호출로 2차 표출해내고, 이 식별자 값 쿼리를 머신러닝 엔진의 필터 인자 `(?drive=)`로 넘기는 네트워크 패킷 페이로드가 관찰된다면 당사 특허의 핵심 오염 격리 철학(Isolation Schema)을 무단 유용한 것으로 판별.
*   **통신 포트 인바운드 차단 시 무작동 여부 역추적**: 데이터 수집 환경이 철저한 폐쇄망, 혹은 인바운드 방화벽이 차단된 상태임에도 에이전트의 단방향 POST/Push 통신만으로 중앙 대시보드 토폴로지에 스토리지 형상이 동적으로 그려진다면 이 역시 당사의 Zero-Touch Auto-Discovery 모델과 동일한 통신 캡슐화를 침해한 상태로 적발 가능.
